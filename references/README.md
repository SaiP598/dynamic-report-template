# Visual reference policy

The assessment PDF was used only to understand visual layout. It is not needed at
runtime and should not be added to the application. Report content uses synthetic
fixtures; patient identifiers, clinical findings, real contact details and source pages are not copied into generated reports.
The Proove company name and standalone logo are the sole source branding retained
at the user's explicit request.

The previous project-local source attachment and derived clinical PDF/image copies
were removed. `private/` remains ignored as a precaution, not a runtime dependency.
